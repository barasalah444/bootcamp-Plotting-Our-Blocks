# Plotting Our Blocks 🧱

A frontend layout challenge from the Coding Dojo curriculum. The objective of this assignment is to accurately replicate a specific multi-colored block layout utilizing fundamental CSS positioning techniques, specifically focusing on `inline-block` behavior, exact mathematical spacing, and box model mechanics.

## 🎯 Objective

To recreate the following wireframe layout purely using custom CSS without relying on modern layout systems like Flexbox or CSS Grid:

* **Grey Container:** The main wrapper handling the overall page boundaries.
* **Green Top Navigation:** Full-width header component.
* **Blue Side Navigation:** A left-aligned vertical sidebar.
* **Red Main Body:** The parent container holding sub-contents, aligned perfectly next to the sidebar.
* **Three Yellow Sub-contents:** Evenly distributed content blocks within the main section.
* **Purple Advertisement:** A bottom-aligned banner stretching across the main layout area.

---

## 🛠️ Technologies Used

* **HTML5** - For structural semantic markup.
* **CSS3** - For complete layout, spacing, and styling.
    * `display: inline-block` (For horizontal alignment)
    * `vertical-align: top` (To counter baseline alignment quirks)
    * `box-sizing: border-box` (For precise inner spacing control)
